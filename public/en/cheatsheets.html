Security03 / 05
"An enterprise agent should not have unlimited autonomy."
Identity & Data
  • OAuth2/OIDC/JWT — scope = exactly the user's permission.
  • Never raw secrets in the LLM's context.
  • PII: minimize what enters the context, not just what gets persisted.
Governance
  • RBAC per tool, based on the user's role.
  • Audit log: who, which tool, with what args, result.
  • Human-in-the-loop for irreversible actions.
AI Security (OWASP-style)
  • Prompt injection — treat external content as data, never as instruction.
  • Excessive agency — fixed with architecture (minimum scope), not with the prompt.
  • Data exfiltration — allowlist of destinations, no arbitrary fetch.
  • Insecure output handling — LLM output = untrusted input.
Distributed Systems & Cloud04 / 05
Key concepts
  • CAP — during a partition: consistency or availability.
  • Saga — steps with compensating actions, not distributed ACID.
  • Outbox — event + state change in the same local tx.
  • Idempotency — key generated at start, not on each retry.
  • Exactly-once — doesn't exist; simulated with at-least-once + idempotency.
